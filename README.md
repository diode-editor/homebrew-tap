# homebrew-tap

Homebrew tap for [Diode](https://github.com/diode-editor/diode), a terminal text editor with the
VS Code keyboard layout, VS Code extensions and LSP.

```sh
brew install diode-editor/tap/diode
```

macOS (Apple Silicon, Intel) and Linux (x64, arm64). `diode` is a **cask**: it links the single-file
binary from the matching [GitHub release](https://github.com/diode-editor/diode/releases) into
`$(brew --prefix)/bin`. Nothing is compiled, so no Xcode Command Line Tools are required.

`Casks/diode.rb` is generated by `packaging/render.mjs` in the main repository and pushed here by
its release workflow on every tag. Do not edit it by hand: the next release overwrites it.
